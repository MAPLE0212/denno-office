オフィスを見る マイページ

このスマホでは、まだだれか分かりません

このスマホで一度だけ、自分のマイページを開いてください。そのあとはタグにかざすだけで座れます。

マイページは、登録したあとに出たページ（）です。タグをかざしたときに開くブラウザで、このページと同じアドレス（）から開いてください。はじめての人は 登録 から。

NFC タグに書き込む URL

    「NFC Tools」などのアプリで、席ごとのタグに「URL」として書き込んで机に貼ります。スマホをかざすとその席に座り、もう一度かざすと帰ります（席が空く）。離席中にかざすと在席に戻ります。

    スマホは会社の Wi-Fi につないでおいてください。この Mac の IP アドレスが変わると URL も変わるので、IP は固定しておくのがおすすめです。
