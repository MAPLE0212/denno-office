# 席の決め方（固定席とフリーアドレス）

サーバを起動するときに、席の決め方を選びます。

```bash
node server/server.js                  # 固定席（既定。SEAT_MODE=fixed と同じ）
SEAT_MODE=free node server/server.js   # フリーアドレス
```

プログラムは 1 つで、変わるのは「席の決め方」と「Dial の役割」だけです。名簿・カード・キャラ・ひとりごとは同じものを使います。モードを切り替えても名簿とカードはそのまま残り、Dial の役割もモードごとに覚えておくので、戻せば元どおりになります。

| | 固定席（`fixed`） | フリーアドレス（`free`） |
|---|---|---|
| 席 | 一人ずつ決まっている（1 席に 1 人） | その日に座る席を、その場で決める |
| 名簿の席 | その人の席 | 「いつもの席」（なくてもよい・重なってもよい）。席を選ばずに在席にすると、空いていればそこに座る |
| 在席でないとき | 不在 | 席を取ったまま外している =「離席」、席が空いている = 帰った |
| 夜のリセット（`RESET_AT`） | 全員を不在に戻す | 全員の席を空ける |
| Dial の役割 | 全体用 / 個人用 / 未設定 | 机（A1〜B3）/ 未設定 |
| 座り方 | カードをかざす・マイページ | 机の Dial にカード・席の NFC タグにスマホ・マイページの席の図 |

## はじめに

1. サーバを起動する（上）
2. Dial に電脳オフィスのプログラムを書き込み（README の「Dial 版」。Wi-Fi は `firmware/denno_config.h`）、電源を入れる。サーバとつながると `/admin` にその Dial が出てくる（画面下の「Dial 1A2B」の 4 桁で見分ける）
3. `/admin` で Dial の役割を決める
   - 固定席：入口などに置く Dial は「全体用」、自分の机に置く Dial は「個人用」にして持ち主を選ぶ
   - フリーアドレス：置いた机（A1〜B3）を選ぶ
4. 使う人は `/join` で登録する。カードを Dial にかざすと 4 桁の番号が出るので、それを入れる（あとからマイページの「カード」でもよい。番号は 10 分で切れる）

最初の起動で `server/members.json` があれば、そこから名簿を作ります。無ければ `members.example.json` の 6 人を「サンプル」として入れます。サンプルの人は、誰かが登録すると入れ替わります（固定席はその席のサンプルだけ、フリーアドレスはサンプル全員）。

## 固定席

### Dial の役割

| 役割 | カードをかざすと | つまみ・画面 |
|---|---|---|
| 全体用 | 登録したカードなら誰でも、その人の在席 / 不在 | 回す・タップで席を選んで名前を見るだけ |
| 個人用 | 持ち主のカードだけ。ほかのカードは「〇〇さん専用」 | 押す・タップ = 持ち主のひとこと選び、長押し = 持ち主の在席 / 不在 |
| 未設定 | 全体用と同じ | 全体用と同じ |

- 個人用の Dial は、持ち主が不在のあいだ背景がゆっくり明るくなったり戻ったりします（「いるのに不在のまま」に気づけるように）。
- 個人用にするのは `/admin` だけです（持ち主を選ぶ）。個人用の Dial は持ち主以外のカードを受け付けないので、カードの登録番号は全体用か未設定の Dial で出します。

## フリーアドレス

### 座り方

| どこで | どうする |
|---|---|
| 机の Dial | カードをかざす。もう一度かざすと帰る（席が空く） |
| 席の NFC タグ | スマホでタッチする（下の「NFC タグ」） |
| マイページ | 席の図で空いている席を押す。帰るときは「帰る（席を空ける）」 |

カード・NFC タグのどちらでも、結果は同じ決まりです。

| そのとき | どうなるか |
|---|---|
| まだ座っていない・ほかの席にいる | この席に座る（在席）。前の席は空く |
| ほかの人が座っている席 | その人は帰り忘れとして席を空け、自分が座る |
| この席に座っていて在席中 | 帰る（席が空く） |
| この席に座っていて離席中 | 在席に戻る |
| 机がまだ決まっていない Dial | 「机が未設定」と出る（何も変えない） |

マイページの席の図では、ほかの人が座っている席は押せません（帰り忘れの人がいるときは、その机の Dial かタグで座り直します）。

机の Dial のつまみ：押す・タップ = その机の人のひとこと選び、長押し = その机の人の在席 ⇔ 離席（離席中も席は取ったまま。オフィスには「離席」の札が出る）。

### NFC タグ

席ごとに NFC タグ（NTAG213 などのシール）を貼ると、スマホでタッチして座れます。

1. スマホかパソコンで、社内 LAN のアドレスの `/tap`（例 `http://192.168.1.10:8080/tap`）を開くと、席ごとの URL（`…/tap/A1` など）が出る
2. 「NFC Tools」などのアプリで、その URL を各席のタグに書き込んで机に貼る
3. スマホをタグにかざすとブラウザが開き、その席に座る。初めてのときだけ「このスマホはだれのか」を選ぶ

- スマホは会社の Wi-Fi につないでおきます。サーバの PC の IP アドレスが変わるとタグの URL も変わるので、IP は固定がおすすめです。
- 画面を出したくない iPhone の人は、「ショートカット」アプリのオートメーション（NFC）で、`/api/members/<id>/tap` に `{"seat":"A1"}` を POST する動作を作ると、かざすだけで切り替わります。

## カード

Dial の読み取り部品は ISO14443A（MIFARE など、よくある白い IC カード）だけ読めます。Suica・PASMO などの FeliCa は読めません。スマホや一部の社員証のように、かざすたびに番号が変わるカードは「使えません」と出ます。手元のカードが読めるかは `firmware/tests/dial_card/` で確かめられます（`pio run -e dial-card-test -t upload`。戻すときは `-e m5stack-dial` で書き直す）。

カードの番号はサーバに **そのまま保存しません**（番号から作った指紋だけを `server/data/registry.json` に持ちます）。ただしカードの番号は専用の道具で複製できるので、在席ボードには十分ですが、鍵の代わりには使わないでください。

### Dial の代わりに Unit RFID を使う

机ごとに Dial を置くのが大げさなら、カードを読む部分だけを [Unit RFID](https://docs.m5stack.com/ja/unit/Unit_RFID) にする手もあります。中身は MFRC522（I2C 0x28）で、Dial の中の読み取り部品と同じ使い方です。違いはつなぐ先だけで、Dial の中の部品は内部の I2C（`M5.In_I2C`）、Unit RFID は外の端子（Port A、`M5.Ex_I2C`）です。サーバは読み取り器の種類を気にしません。端末は次の 2 つだけ守れば、Dial と同じように使えます。

- 同期のときに `GET /api/device?board=dial&mac=<自分の MAC 12 桁>` を呼ぶ（`/admin` に出て、`#dial` 行で役割が返る）
- カードを読んだら `POST /api/card` に `{"mac":"<MAC>","uid":"<カードの番号 16 進>"}` を送る（答えは下の表）

## サーバの API

| メソッド | パス | 内容 |
|---|---|---|
| POST | `/api/register` | 登録 `{ name, seat?, code? }` → `{ id }`（固定席は seat が要る） |
| GET | `/api/codes/<番号>` | Dial に出た 4 桁の番号の確認 → `{ dialRole, usedBy }` |
| POST / DELETE | `/api/members/<id>/card` | カードを結ぶ `{ code }` / 外す |
| PATCH | `/api/members/<id>` | `{ seat: "A2" \| null }` で座る / 帰る（フリーアドレス。ほかの人がいれば 409） |
| POST | `/api/members/<id>/tap` | `{ seat: "A2" }` NFC タグからのタッチ（フリーアドレス）→ `{ action: "sit" \| "back" \| "leave", state }` |
| PATCH / DELETE | `/api/admin/members/<id>` | 名前・席を直す `{ name?, seat?, card?: null }` / 消す |
| GET | `/api/dials` | Dial の一覧 |
| PATCH / DELETE | `/api/dials/<mac>` | 役割を変える `{ role, owner?, seat?, label? }` / 一覧から消す。role は固定席 `none` `shared` `personal`、フリーアドレス `none` `desk` |
| POST | `/api/card` | Dial から `{ mac, uid }`。答えはタブ区切りの 1 行（下） |

`/api/card` の答え：

| 答え | いつ |
|---|---|
| `code 1234` | 未登録のカード |
| `in 名前` / `out 名前` | 固定席で在席 / 不在にした |
| `deny 持ち主` | 固定席で、ほかの人の個人用の Dial |
| `sit 名前 席` / `back 名前 席` / `leave 名前 席` | フリーアドレスで座った / 離席から戻った / 帰った |
| `nodesk 名前` | フリーアドレスで、机が未設定の Dial |

`/api/device` の `#dial` 行：`#dial <TAB> 役割 <TAB> 席 <TAB> 持ち主の名前`。役割は `none` / `shared` / `personal`（席 = 持ち主の席）/ `desk`（席 = 置いた机）。`#mode` 行（`fixed` / `free`）は StopWatch と Dial が不在の札を「不在」か「離席」にするのに使います。

`#t <TAB> 席 <TAB> 種類 <TAB> 残り秒 <TAB> 全体の秒`：Dial で出した時間のひとこと（種類は `focus` 集中・`rest` 休憩・`meeting` 会議・`out` 外出）。Dial のタイマー画面（左右にスワイプ）が使います。ひとことを出すときに `comment.timer` で種類を送ると、この行が出ます。

保存先は `server/data/`（git に入りません）：`registry.json`（名簿・カードの指紋・Dial の役割）、`state.json`（在席・ひとりごと・キャラ・フリーアドレスの今日の席）。

## 決めていないこと

- 認証はありません。URL を知っていれば誰でも席・カード・Dial の役割を変えられます。社内 LAN の中だけで使ってください。
- 島は 1 つ・6 席のままです。
- StopWatch 版はカードを読めないので、今までどおり島を見せる端末です（だれもいない席は空いて見えます）。
