# Claude Code でミニキャラを作る（コードを書かずに）

電脳オフィスのキャラは three.js のコードでできていますが、コードが書けなくても大丈夫です。[Claude Code](https://claude.com/claude-code) に「こんな子を作って」と話しかけると、Claude がコードを書き、チェックまでしてくれます。あなたは見た目を見て「ここをこう直して」と言うだけです。

このリポジトリには Claude 向けの説明書 [CLAUDE.md](../CLAUDE.md) が入っているので、キャラの決まり（雛形から作る、自分のフォルダに置く、チェックを通す など）は、最初から Claude が知っています。

## 用意するもの

- **Claude Code**：[公式ページ](https://claude.com/claude-code) の手順で入れます。ターミナルで使う版と、デスクトップアプリ（Code タブ）があり、どちらでも作れます。使うには Claude の有料プランか API の契約が要ります。
- **Node.js 18 以上**：キャラのチェックとサーバに使います。
- **git**：リポジトリを手元に持ってくるのに使います。

## 1. リポジトリを手元に持ってくる

作ったキャラをみんなに公開したい（Pull Request を送りたい）なら、GitHub でこのリポジトリを **Fork** してから、自分の Fork を clone します。自分のオフィスだけで使うなら、そのまま clone すれば十分です。

```bash
git clone https://github.com/<あなたのユーザー名>/denno-office.git
cd denno-office
```

## 2. Claude Code を開いて、作りたい子を伝える

このフォルダで Claude Code を開きます（ターミナルなら `claude`、デスクトップアプリならフォルダを選ぶ）。最初に、次の3つを伝えると話が早いです。

- **作成者の名前**（フォルダ名になる。英小文字・数字で。GitHub のユーザー名がおすすめ）
- **公開するか**（公開するなら `characters/<作成者>/`、自分用なら `characters/local/`）
- **どんな子か**（髪・服・色・小物・雰囲気）

たとえば:

> 作成者は alice で、公開用のキャラを作りたいです。
> ねこみみのフードをかぶった女の子。黄色いパーカーにデニムのショートパンツ、白いスニーカー。髪はオレンジのショートボブ。

Claude は雛形 `characters/_template.html` をコピーしてキャラを作り、一覧 `characters.json` に「準備中」で足し、チェック（`tools/check_chara.mjs`）を通してから、できたことを教えてくれます。

## 3. 見る

できたキャラの html（例 `characters/alice/cat-hood.html`）をブラウザで開くと、その子だけを回して見られます。「座って作業 / 座って待機 / 立ち」のポーズも切り替えられます。

ファイルを直接開いてうまく表示されないときは、リポジトリのフォルダで簡単なサーバを動かして開きます（Python が入っていれば使えます）。

```bash
python3 -m http.server 8800
```

`http://localhost:8800/characters/alice/cat-hood.html` を開きます。

オフィスに座らせて見たいときは、サーバを起動してマイページでそのキャラを選びます（「準備中」のあいだは選べないので、Claude に「選べるようにして」と頼むか、`characters.json` の `"wip": true` を外します）。

```bash
node server/server.js
```

`http://localhost:8080/me` で自分を選び、キャラのタブから選ぶと、`http://localhost:8080/` のオフィスに座ります。

Claude Code のデスクトップアプリなら、Claude に「ブラウザで見せて」と頼むと、上のサーバを動かしてアプリの中のブラウザで開き、画面を見ながら直してくれます。

## 4. 言葉で直す

見ながら、直したいところを伝えます。うまく伝えるコツ:

- **場所・形・大きさを具体的に。** 「髪をかわいく」より「前髪を眉の上までの長さにして、横はあごの下まで」。
- **一度に1〜2か所ずつ。** たくさん同時に頼むより、1つずつ確かめるほうが早く仕上がります。
- **比べる相手を出す。** 「maple/c02 のボブくらいの長さで」「今より2割くらい大きく」。
- **絵を見せる。** 自分で描いたラフや、自分の持ち物の写真を貼って「この形にして」と頼めます（他の人が描いたイラストをそっくりまねるのは避けてください。下の「公開するときの決まり」）。
- **戻せる。** 「さっきの形に戻して」と言えば戻してくれます。

たとえば:

> ねこみみをもう少し大きくして、先を丸く。耳の内側をピンクにして。
> 座ったときにフードが椅子にめり込んでいるので、少し小さくして。
> 輪郭の光を、パーカーだけ少し弱めて。

## 5. 仕上げる

気に入ったら、Claude に「完成にして」と伝えます。

- 「準備中」を外して、マイページで選べるようにします。
- マイページ用の写真（`<id>_front.png`）は、写真を撮る道具（README の「tools の環境」）があれば Claude が撮ってくれます。無くても、Pull Request を送れば GitHub Actions が撮ってくれます。
- 最後にもう一度チェックを通します。

## 6. みんなに公開する（Pull Request）

> コミットして、Pull Request を作って。

と頼むと、Claude がコミットと Pull Request の作成を手伝ってくれます（送る前に確認してくれます）。GitHub の操作に慣れていなければ、手順をそのつど聞いてもかまいません。PR を送ると GitHub Actions がチェックと写真撮影をし、管理者がコードを読んでから取り込みます。

### 公開するときの決まり

- 変えるのは自分のフォルダ `characters/<作成者>/` の中だけ。
- キャラは自分で考えたものにする。他の人のイラストやキャラを、許可なくなぞったりまねたりしない。
- 取り込んだキャラは MIT License で公開されます（誰でも改変・再配布・商用利用できます）。

詳しくは [CONTRIBUTING.md](../CONTRIBUTING.md) を見てください。

## うまくいかないとき

- **チェックでエラーが出た**：エラーの文をそのまま Claude に見せて「直して」と頼めば直してくれます。
- **思った形にならない**：形の名前を変えて言い直す（「とんがり」→「三角の」「円すいの」）、似た形の身近なもの（「おにぎりみたいな形」「しずく形」）で伝える、絵を貼る、が効きます。
- **作り直したい**：「雛形からやり直して」と言えば、最初から作り直せます。
- **作風をそろえたい**：自分のキャラに共通の作り方（目の形、前髪の作り方など）が決まってきたら、「この作り方を作風として STYLE.md に書いて」と頼みます。自分のフォルダの `STYLE.md`（`characters/<作成者>/STYLE.md`）にまとめてくれて、次からはキャラを作る前に Claude がそれを読むので、同じ作りでそろいます。
